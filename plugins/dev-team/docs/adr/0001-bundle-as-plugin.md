# 0001: 開発ループ一式を 1 つのプラグインにまとめ、工程ごとにスキルを分ける

- ステータス: accepted（2026-08-15）

## 背景
開発ループ一式（要件のチケット化 ticket-intake、自律実装 dev-loop、監視盤 dev-loop-dashboard）を「開発フレームワーク」として 1 つにまとめたい。それまでは 3 つが独立したスキルとして置かれ、名前空間もエージェント定義も共有していなかった。

## 決定
Claude Code のプラグイン `dev-team`（`plugins/dev-team/`）を作り、既存 3 スキルをその中へ移す（ticket-intake は spec-intake に改名）。工程ごとにスキルを分けたまま、プラグインの名前空間（`/dev-team:<skill>`）でまとめる。プラグイン自身の仕様と ADR もプラグインの中（`docs/`）に置く。

## 検討した選択肢
- スキル群のまま（プラグイン化しない）: 名前空間・agents・evals・plugin details といったプラグインの機構が使えず、「フレームワーク」としてのまとまりが表現できない
- 単一の巨大オーケストレータースキル: SKILL.md が肥大化し、工程単体の起動と改修ができない

## 影響
- プラグインの名前空間（`/dev-team:<skill>`）・agents・evals が使える
- 起動名が変わる（`/dev-loop` → `/dev-team:dev-loop`）
- プラグインの中のファイルを参照するときは、`${CLAUDE_PLUGIN_ROOT}` / `${CLAUDE_SKILL_DIR}` を使う（読み込み元はマーケットプレイスの登録の仕方で変わるため、絶対パスで書かない。ADR 0014）
