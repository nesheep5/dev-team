# dev-team の ADR

dev-team プラグイン自身の設計判断を記録する。追記のみ。決定を変えるときは新しい ADR を書き、古い方のステータスを `superseded by NNNN` にする。

ADR 0007 が参照する日付付きの旧設計書は、仕様（`docs/spec/`）へ取り込んだ後に廃止しており、このリポジトリには無い。

ステータスは決定の有効性を表し、実装の有無は表さない。accepted のまま実装していない決定があるので、実装の状況は下の一覧の「実装」列と [ROADMAP](../ROADMAP.md) で見る。

## 書式（MADR 軽量版）

- タイトル（`# NNNN: <決定の要約>`）
- ステータス: proposed / accepted / superseded by NNNN
- 背景: なぜ判断が必要になったか
- 決定: 何をどうするか
- 検討した選択肢: 採らなかった案と理由
- 影響: この決定で楽になること・制約になること
