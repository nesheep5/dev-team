# dev-loop-dashboard — ループ監視盤の起動

任意のディレクトリから次を実行する（サーバーは background で起動し、会話をブロックしない）:

    node ${CLAUDE_SKILL_DIR}/server.mjs --open

対象の決め方（優先順）:

| 指定 | 対象 |
|---|---|
| `--project <path>`（繰り返し可） | 指定したリポジトリだけ。台帳が無くても動く。名前は basename（衝突したら `親/basename`） |
| `--ledger <path>` | その台帳の全プロジェクト |
| 引数なし | 状態ディレクトリ（環境変数 `DEV_TEAM_HOME`、未設定なら `~/.claude/dev-team`）の `projects.json` があれば全プロジェクト、無ければ cwd の 1 リポジトリ |

台帳の形は `{"projects": [{"name": "<一意な名前>", "path": "<リポジトリの絶対パス>"}]}`（詳細は仕様の「台帳」）。

- 既定ポートは 4649。塞がっていれば自動で空きへずらす。固定したい場合は `--port <N>`
- `--open` で既定ブラウザを開く。URL は起動ログに出る
- データ源はプロジェクトごとに 2 つ: `<path>/.claude/dev-loop/events.jsonl`（dev-loop が追記する速報）と gh CLI（`<path>` を cwd にした 30 秒ポーリングの正）。片方が欠けたプロジェクトはその項目だけ劣化表示になり、他は通常表示
- 画面はプロジェクトごとの縦積み（ヘッダ・5 駅レーン・依存 DAG・ログ）で、上部に稼働ループ数・blocked 合計・エラー数の横断サマリ
- 動作確認やデザイン調整には `--demo`（gh 不要・同梱フィクスチャ 2 組を表示。`--project` / `--ledger` より優先）
- プロジェクト名（台帳の `name`）は一意にすること。重複・空の台帳・値の無いフラグは起動せず exit 1 で理由を出す
- 1 つの gh が 20 秒応答しなければその項目だけ `ghError` にし、他は止めない

仕様は `${CLAUDE_PLUGIN_ROOT}/docs/spec/dashboard.md`。

## 前提

- Node 18 以上
- 対象リポジトリで gh CLI が認証済み（`--demo` 時は不要）。1 リポジトリモードでは cwd がリポジトリであること

## 停止

起動ログに表示される PID（例: `PID: 12345`）を `kill <PID>` する。プロジェクト数にかかわらずプロセスもポートも 1 つ。サーバーは表示専用で状態を持たないためいつ止めてもよい。
